# iPhone and browser listening
<!-- keywords: iphone, ios, ipad, apple, browser, chrome, safari, web, link, no app, web player, tablet, iphone par, browser mein, bina app, safari -->

## Can I listen on an iPhone?
Yes, through the browser. Open the host's link in Safari or any browser on the iPhone and tap **Start listening**; no app is needed. There is no iPhone app yet.
1. Connect the iPhone to the same Wi-Fi as the host, or to its hotspot.
2. Scan the QR code with the iPhone camera, or open the link.
3. Tap **Start listening**.
**iPhone:** the browser player pauses when the screen turns off; keep the screen on while listening.

## How do I listen in a browser without installing anything?
Open the host's link (http://IP:8790/?k=KEY) in any browser on a phone, tablet or laptop and press **Start listening**. The browser player has a volume slider and joins the shared deadline like the apps.
1. Get the link from the host: Windows **Listeners > Copy link**, Android host **Join > Copy link**.
2. Open it in the browser on the same Wi-Fi or hotspot.
3. If the host uses a room PIN, type it when asked ("Enter the room PIN").

## Can an iPhone share its sound to other phones?
No. Only a Windows laptop or an Android phone (Android 10 or newer) can be the host. An iPhone can only listen, through the browser.

## Why does the browser player stop when the screen turns off?
Browsers, especially on iPhone, pause web pages in the background. On Android, the Dual Earbuds app keeps playing with the screen off; in Chrome on Android, tap Start once and lock the phone, and a media notification keeps it running.
1. Android: use the Dual Earbuds app for guaranteed background play.
2. Chrome on Android: set Chrome's battery to Unrestricted (or No restrictions); on Xiaomi, Realme, OPPO and Vivo lock Chrome in Recents.
3. iPhone: keep the screen on.

## Is the browser player as good as the app?
It plays the same sound and joins the same deadline, but it uses WebSocket instead of UDP, so on weak Wi-Fi it can stall more often. It also can't calibrate earbuds, so it uses the delay the browser reports, or an estimate.
**Android:** for the best sync and background play, install the Dual Earbuds app.

## Does the browser listener count toward the listener limit?
Yes. Every browser tab that listens counts as one listener, toward the limit of 8, or 16 in Party mode.

## Can I listen in a browser on a laptop or tablet?
Yes. Any device with a browser on the same Wi-Fi or hotspot can open the host's link and press **Start listening**, including a Mac, a Chromebook or a tablet. For a Windows laptop, the Dual Earbuds app's **Listen** page is better because it uses UDP and can calibrate.

## Why does the browser page open but play nothing?
Browsers only play sound after you tap the page, so press **Start listening** first. If it still stays silent, the host may not be sharing yet, or the device is on a different network.
1. Press **Start listening** and turn the page's **Volume** up.
2. Check that the host shows **Stop sharing** (it is sharing) and something is playing.
3. Make sure the device is on the host's Wi-Fi or hotspot; on public Wi-Fi use a hotspot.
4. If the page asks for a PIN, ask the host for the room PIN.
